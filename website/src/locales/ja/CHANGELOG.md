# 更新履歴

QuickDesk の各リリースの変更点（日本語訳）。原文はリポジトリ直下の CHANGELOG.md です。ここにないリリースは英語で表示されます。

## Unreleased

### 新機能
- アプリが Web サイトと同じ言語に対応しました。英語とベトナム語に加えて、簡体字中国語、日本語、ヒンディー語、スペイン語、フランス語、アラビア語（右から左）、ベンガル語、ロシア語、ポルトガル語（ブラジル）、インドネシア語を選べます。設定 → 言語で選択してください。「システムと同じ」は macOS と Windows でもシステムの言語に従うようになりました。トレイメニューと「新機能」の説明も同じ言語で表示されます。

## 0.6.1 — 2026-10-12

### 修正
- macOS：クリップボードのポップアップで項目を選ぶと、入力していたテキスト欄に再び貼り付けられるようになりました。QuickDesk はアプリのアクティブ化を要求する代わりに自分から一歩下がり、macOS がそのアプリとテキスト欄にフォーカスを戻すようにします。新しい macOS ではアクティブ化の要求が中途半端にしか聞き入れられないことがあるためです。

## 0.6.0 — 2026-10-11

### 新機能
- QuickDesk for macOS（Apple シリコン、macOS 11 以降）：同期できるメモ、テキスト・画像・ファイルのクリップボード履歴、使っていたアプリへの ⌘V による自動貼り付け、ポート、言語のバージョン、AI の利用量を、メニューバーから。ショートカットは ⌃⌥N / V / P です。ターミナルで `curl -fsSL https://quickdesk.click/install.sh | bash` を実行するか、ダウンロードページの .dmg でインストールできます。他の OS と同じく自動でアップデートします。アプリはまだ Apple の公証を受けていないため、ブラウザでダウンロードした .dmg は macOS が初回起動をブロックします。開き方はダウンロードページにあります（システム設定 → プライバシーとセキュリティ → このまま開く）。
- Mac では AI タブで Claude の上限も表示できます。Mac の Claude Code はログイン情報をキーチェーンに保存しており、QuickDesk はあなたが許可したあとにだけ読み取ります。

### 修正
- リリースにパッケージが欠けているとき、インストールスクリプトが何も言わずに止まる代わりに、どのパッケージがないかを伝えるようになりました。

## 0.5.0 — 2026-10-11

### 新機能
- QuickDesk for Windows 10 / 11（64 ビット）：同期できるメモ、テキスト・画像・ファイルのクリップボード履歴、使っていたアプリへの自動貼り付け、ポート、AI の利用量を、同じ Win+Alt+N / V / P のショートカットで。PowerShell で `irm https://quickdesk.click/install.ps1 | iex` を実行するか、ダウンロードページからインストールできます。管理者権限なしでご自分のユーザーにインストールされ、自動でアップデートします。ランタイムタブは mise、rustup、uv を通じて動きます：ワンクリックで mise をインストールし、Node、Python、Go などを追加でき、「PATH を修正…」が管理者権限なしでそれらのフォルダーをアカウントの PATH に追加します。
- ランタイム：まだコンピューターにない言語が「言語を追加」に一覧され、mise ですぐにインストールできます。

### 改善
- ランタイム：Rust のチャンネルにもアップデートボタンが付きました。rustup に新しい stable（または beta、nightly）があるとチャンネルに ↑ が表示され、クリックひとつで `rustup update` を実行します。

## 0.4.0 — 2026-10-10

### 新機能
- プログラミング言語のバージョンを扱うランタイムタブ：新しいターミナルで実際に動く Node.js、Python、Rust、Go… とその出どころを確認し、バージョンのインストールとアンインストール、デフォルトの選択、プロジェクトごとの固定ができます。QuickDesk は nvm、uv、rustup、mise を通じて動き、システムのパッケージには一切触れません。
- インストール済みの系列に新しいリリースが出ると（たとえば 22.23.3 に対する Node 22.24.1）、そのバージョンにアップデートボタンが表示されます。古い方は削除するまで残ります。
- バージョンマネージャーのない言語（たとえば apt で入れた Go）は、ワンクリックで mise を導入できます。mise は GitHub のリリースからダウンロードし、その SHA-256 と照合します。
- 「開いているターミナルにもすぐ反映する」：変更がすでに開いているターミナルにも次のプロンプトから反映され、`cd` したときに Node がいちばん近い `.nvmrc` に従います。PATH が邪魔をしているときは、タブが理由を示し、シェルファイルに追加する行をバックアップ付きで提案します。

### 改善
- ダウンロードページに、ターミナルからダウンロードしてインストールするための完全なコマンドを表示します。
- バージョン一覧で、各系列の最新リリース、LTS のみ、またはすべてを表示できます。

## 0.3.1 — 2026-10-09

### 新機能
- 同期が組み込みになりました：設定 → 同期でオンにして、同期コードで他のコンピューターを参加させます。アカウント、メール、ストレージの設定は不要です。メモは引き続きコンピューターを離れる前に暗号化され、QuickDesk Cloud には暗号文しか保存されません。

### 修正
- 以前のバージョンのメモ、クリップボード履歴、設定が戻りました。0.2.0 と 0.3.0 へのアップデートでは、データを移す代わりに空のフォルダーから始まっていました。QuickDesk は今後自分でデータを移し、古いフォルダーはバックアップとして残します。
- 設定を開いても、他のタブの色付きの点が灰色にならなくなりました。

### 改善
- 自前の S3 や R2 バケットを通じた同期の提供をやめました。使っていた場合は、設定 → 同期に案内を表示したうえで同期を一度オフにします。メモはコンピューターに残ります。
- トップバーの AI 利用量メニューは追跡中のツールだけを表示し、上限ごとに緑・黄・赤のバーとその下にリセット時刻を表示します。別のツールは Track で選べます。

## 0.3.0 — 2026-10-09

### 新機能
- QuickDesk に専用のアドレスができました：[quickdesk.click](https://quickdesk.click)。ダウンロードとアップデートはここから届きます。
- 本格的なウェブサイト：適切なパッケージを提案するダウンロードページ、ドキュメント、更新履歴、プライバシーのページを英語とベトナム語で。

### 改善
- データの保存場所が `~/.local/share/click.quickdesk` になりました。QuickDesk は初回起動時に自分でデータを移し、メモ、クリップボード履歴、設定はそのまま残ります。
- アップデート後の再起動がより確実になりました。

## 0.2.2 — 2026-10-09

### 新機能
- QuickDesk が自分でアップデートするようになりました。バックグラウンドで新しいバージョンを確認し、変更点を伝え、あなたが選んだときだけインストールします。アップデートはインストール前に必ず QuickDesk の署名鍵で検証されます。
- 設定 → アップデート：バージョンの確認、今すぐ確認、自動確認のオフ。
- アップデート後、QuickDesk は新機能を一度だけ表示します。
- ダウンロードページがベトナム語でも読めるようになり、GitHub のソースコードへのリンクも付きました。

### 改善
- どこでも同じアイコン：Dock、アプリメニュー、ウィンドウ、トレイで QuickDesk のアイコンを共有します。

## 0.2.1 — 2026-10-08

### 新機能
- アプリとダウンロードページで共通の新しい見た目：セクションごとの色（メモ、クリップボード、ポート、AI）、ポップアップでのキーボードのヒント、macOS 風のタブバー。
- アプリ全体で絵文字の代わりに線のアイコンを使います。
- よりすっきりした macOS 風のトレイメニュー：短いラベル、「Save クリップボード History」のチェックマーク、ツールごとにまとめた AI の上限。

### 改善
- ダウンロードページのデモは、サンプルデータで動く本物のアプリです。

## 0.2.0 — 2026-10-08

### 新機能
- Ubuntu/Debian（.deb）、Fedora（.rpm）、その他のディストリビューション（AppImage）向けのパッケージを、QuickDesk のダウンロードサイトで公開しました。

### 改善
- データは QuickDesk の新しいデータフォルダー（`~/.local/share/io.github.tankgum.quickdesk`）へ自動的に移ります。
