# 更新日志

QuickDesk 每个版本的更新内容（简体中文译文）。英文原文在仓库根目录的 CHANGELOG.md；这里缺少的版本会以英文显示。

## 0.6.1 — 2026-10-12

### 修复
- macOS：在剪贴板弹窗中选择一条记录后，又能粘贴到你刚才输入的文本框中了。QuickDesk 现在会主动退到后台，让 macOS 把焦点还给那个应用和文本框，而不是请求激活该应用——较新的 macOS 版本可能只会执行一半。

## 0.6.0 — 2026-10-11

### 新功能
- QuickDesk for macOS（Apple 芯片，macOS 11 或更高版本）：可同步的笔记、包含文字、图片和文件的剪贴板历史、用 ⌘V 自动粘贴到你刚才使用的应用、端口、语言版本和 AI 用量，全部在菜单栏中。快捷键是 ⌃⌥N / V / P。可在终端中用 `curl -fsSL https://quickdesk.click/install.sh | bash` 安装，或从下载页面获取 .dmg；它会像其他系统上一样自动更新。该应用尚未经过 Apple 公证：如果 .dmg 是用浏览器下载的，macOS 会阻止首次启动，下载页面说明了如何打开（系统设置 → 隐私与安全性 → 仍要打开）。
- 在 Mac 上，AI 标签也能显示你的 Claude 限额：Claude Code 在那里把登录信息保存在钥匙串中，QuickDesk 只在你允许之后才读取。

### 修复
- 当某个版本缺少软件包时，安装脚本会说明缺少哪个，而不是一声不响地停止。

## 0.5.0 — 2026-10-11

### 新功能
- QuickDesk for Windows 10 和 11（64 位）：可同步的笔记、包含文字、图片和文件的剪贴板历史、自动粘贴到你刚才使用的应用、端口和 AI 用量，快捷键同样是 Win+Alt+N / V / P。可在 PowerShell 中用 `irm https://quickdesk.click/install.ps1 | iex` 安装，或从下载页面获取；它只为你的用户安装，不需要管理员权限，并会自动更新。Runtimes 标签通过 mise、rustup 和 uv 工作：一键安装 mise，添加 Node、Python、Go 等，“Fix PATH…” 会把它们的文件夹加入你账户的 PATH，无需管理员权限。
- Runtimes：电脑上还没有的语言列在 “Add a language” 下，可以通过 mise 直接安装。

### 改进
- Runtimes：Rust 渠道也有了更新按钮。当 rustup 有更新的 stable（或 beta、nightly）时，该渠道会显示 ↑，一键即可为它运行 `rustup update`。

## 0.4.0 — 2026-10-10

### 新功能
- 新增 Runtimes 标签，管理你的编程语言版本：查看新终端实际运行的是哪个 Node.js、Python、Rust、Go…以及它从哪里来，安装和卸载版本，选择默认版本，并为项目固定版本。QuickDesk 通过 nvm、uv、rustup 和 mise 工作，从不改动系统软件包。
- 当已安装的版本线有更新的版本发布时（比如 22.23.3 有了 Node 22.24.1），该版本会显示更新按钮；旧版本会保留，直到你删除它。
- 没有版本管理器的语言（例如通过 apt 安装的 Go）可以一键获取 mise，它从 GitHub 版本发布下载，并用其 SHA-256 校验和核对。
- “Apply right away in open terminals”：更改会在已打开的终端的下一个提示符处生效，并且当你 `cd` 时 Node 会跟随最近的 `.nvmrc`。当 PATH 中有东西挡路时，标签会说明原因，并给出要添加到 shell 文件中的具体内容，同时保留备份。

### 改进
- 下载页面显示从终端下载和安装的完整命令。
- 版本列表可以显示每个版本线的最新版本、仅 LTS 版本或全部版本。

## 0.3.1 — 2026-10-09

### 新功能
- 同步现在是内置的：在 Settings → Sync 中开启，用同步码加入你的其他电脑。不需要账号、邮箱或存储设置。笔记仍然在离开电脑之前就在本机加密；QuickDesk Cloud 只保存密文。

### 修复
- 早期版本中的笔记、剪贴板历史和设置回来了。更新到 0.2.0 和 0.3.0 时，应用从一个空文件夹开始，而没有迁移你的数据；QuickDesk 现在会自行把数据迁移过来，并保留旧文件夹作为备份。
- 打开 Settings 不再让其他标签的彩色圆点变成灰色。

### 改进
- 不再提供通过你自己的 S3 或 R2 存储桶同步。如果你用过它，同步会被关闭一次，并在 Settings → Sync 中附上说明；你的笔记仍保留在电脑上。
- 顶部栏中的 AI 用量菜单只显示你跟踪的工具，每项限额一个绿色、黄色或红色的进度条，下方是重置时间。可在 Track 下选择其他工具。

## 0.3.0 — 2026-10-09

### 新功能
- QuickDesk 有了自己的网址：[quickdesk.click](https://quickdesk.click)。下载和更新都来自这里。
- 一个真正的网站：会推荐合适软件包的下载页面、文档、更新日志和隐私页面，提供英文和越南语版本。

### 改进
- 你的数据现在位于 `~/.local/share/click.quickdesk`。QuickDesk 首次启动时会自行把数据移过去；笔记、剪贴板历史和设置保持不变。
- 更新后的重启更加可靠。

## 0.2.2 — 2026-10-09

### 新功能
- QuickDesk 现在会自动更新。它在后台检查新版本，告诉你有哪些变化，只在你选择时才安装。每次更新在安装前都会用 QuickDesk 的签名密钥进行验证。
- Settings → Updates：查看你的版本、立即检查，或关闭自动检查。
- 更新之后，QuickDesk 会显示一次新内容。
- 下载页面提供越南语版本，并链接到 GitHub 上的源代码。

### 改进
- 处处使用同一个图标：程序坞、应用菜单、窗口和托盘现在都使用 QuickDesk 的图标。

## 0.2.1 — 2026-10-08

### 新功能
- 应用和下载页面共享的全新外观：每个部分（笔记、剪贴板、端口、AI）有自己的颜色，弹窗中有键盘提示，还有 macOS 风格的标签栏。
- 整个应用用线条图标取代了表情符号。
- 托盘菜单采用更简洁的 macOS 风格：简短的标签、“Save Clipboard History” 前的勾选标记，以及按工具分组的 AI 限额。

### 改进
- 下载页面上的演示就是用示例数据运行的真实应用。

## 0.2.0 — 2026-10-08

### 新功能
- 提供 Ubuntu/Debian（.deb）、Fedora（.rpm）和其他发行版（AppImage）的软件包，发布在 QuickDesk 下载站点上。

### 改进
- 你的数据会自动迁移到 QuickDesk 的新数据文件夹（`~/.local/share/io.github.tankgum.quickdesk`）。
