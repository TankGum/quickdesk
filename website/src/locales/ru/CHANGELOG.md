# Изменения

Что изменилось в каждой версии QuickDesk (перевод на русский). Оригинал на английском — в CHANGELOG.md в корне репозитория; версии, которых здесь нет, показываются на английском.

## Unreleased

### Новое
- Приложение говорит на языках сайта: кроме английского и вьетнамского — упрощённый китайский, японский, хинди, испанский, французский, арабский (справа налево), бенгальский, русский, португальский (Бразилия) и индонезийский. Выберите язык в разделе Настройки → Язык; «Как в системе» теперь следует языку системы и на macOS и Windows. Меню в трее и описание «Что нового» тоже на выбранном языке.

## 0.6.1 — 2026-10-12

### Исправлено
- macOS: выбранная во всплывающем окне буфера обмена запись снова вставляется в текстовое поле, в котором вы печатали. Теперь QuickDesk сам отходит в сторону, чтобы macOS вернула фокус этому приложению и полю, а не просит активировать приложение — новые версии macOS могут выполнять такую просьбу лишь наполовину.

## 0.6.0 — 2026-10-11

### Новое
- QuickDesk для macOS (Apple Silicon, macOS 11 или новее): заметки с синхронизацией, история буфера обмена с текстом, изображениями и файлами, автовставка через ⌘V в приложение, где вы работали, порты, версии языков и использование ИИ — из строки меню. Сочетания клавиш — ⌃⌥N / V / P. Установите его из Терминала командой `curl -fsSL https://quickdesk.click/install.sh | bash` или в виде .dmg со страницы загрузки; он обновляется сам, как и на других системах. Приложение пока не нотаризовано Apple: если .dmg скачан через браузер, macOS блокирует первый запуск, а на странице загрузки описано, как его открыть («Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»).
- На Mac вкладка AI может показывать и лимиты Claude: там Claude Code хранит вход в Связке ключей, и QuickDesk читает его только после вашего разрешения.

### Исправлено
- Скрипт установки сообщает, какого пакета не хватает в выпуске, а не останавливается молча.

## 0.5.0 — 2026-10-11

### Новое
- QuickDesk для Windows 10 и 11 (64 бит): заметки с синхронизацией, история буфера обмена с текстом, изображениями и файлами, автовставка в приложение, где вы работали, порты и использование ИИ — с теми же сочетаниями Win+Alt+N / V / P. Установите его из PowerShell командой `irm https://quickdesk.click/install.ps1 | iex` или со страницы загрузки; он ставится для вашего пользователя без прав администратора и обновляется сам. Вкладка Среды работает через mise, rustup и uv: установите mise одним щелчком, добавьте Node, Python, Go и остальные, а «Исправить PATH…» добавит их папки в PATH вашей учётной записи без прав администратора.
- Среды: языки, которых ещё нет на компьютере, перечислены в «Добавить язык» и готовы к установке через mise.

### Улучшено
- Среды: у каналов Rust тоже появилась кнопка обновления. Когда у rustup есть более новый stable (или beta, nightly), канал показывает ↑, а один щелчок запускает для него `rustup update`.

## 0.4.0 — 2026-10-10

### Новое
- Вкладка Среды для версий ваших языков программирования: смотрите, какой Node.js, Python, Rust, Go… на самом деле запускает новый терминал и откуда он берётся, устанавливайте и удаляйте версии, выбирайте версию по умолчанию и закрепляйте версию для проекта. QuickDesk работает через nvm, uv, rustup и mise и никогда не трогает системные пакеты.
- Когда выходит новый выпуск установленной ветки (например, Node 22.24.1 вместо 22.23.3), у версии появляется кнопка обновления; старая остаётся, пока вы её не удалите.
- Языки без менеджера версий (например, Go из apt) могут получить mise одним щелчком: он скачивается из выпусков на GitHub и проверяется по их SHA-256.
- «Применять сразу в открытых терминалах»: изменения доходят до уже открытых терминалов при следующем приглашении, а Node следует ближайшему `.nvmrc` при `cd`. Если что-то в PATH мешает, вкладка объясняет почему и предлагает точные строки для файла оболочки, с резервной копией.

### Улучшено
- На странице загрузки показана полная команда для загрузки и установки из терминала.
- Список версий может показывать последний выпуск каждой ветки, только LTS или все версии.

## 0.3.1 — 2026-10-09

### Новое
- Синхронизация теперь встроена: включите её в Настройки → Синхронизация и подключите другие компьютеры кодом синхронизации. Ни учётной записи, ни почты, ни настройки хранилища. Заметки по-прежнему шифруются на вашем компьютере до того, как покинут его; QuickDesk Cloud хранит только шифротекст.

### Исправлено
- Вернулись заметки, история буфера обмена и настройки из прежних версий. Обновление до 0.2.0 и 0.3.0 начиналось с пустой папки вместо переноса ваших данных; теперь QuickDesk переносит их сам и сохраняет старые папки как резервную копию.
- Открытие Настройки больше не делает серыми цветные точки других вкладок.

### Улучшено
- Синхронизация через собственный бакет S3 или R2 больше не предлагается. Если вы ею пользовались, синхронизация один раз отключается с пояснением в Настройки → Синхронизация; ваши заметки остаются на компьютере.
- Меню использования ИИ в верхней панели показывает только отслеживаемый инструмент: зелёная, жёлтая или красная полоска для каждого лимита и время сброса под ней. Другой инструмент выбирается в Track.

## 0.3.0 — 2026-10-09

### Новое
- У QuickDesk появился свой адрес: [quickdesk.click](https://quickdesk.click). Загрузки и обновления приходят оттуда.
- Настоящий сайт: страница загрузки, подсказывающая нужный пакет, документация, список изменений и страница о конфиденциальности — на английском и вьетнамском.

### Улучшено
- Ваши данные теперь хранятся в `~/.local/share/click.quickdesk`. QuickDesk сам переносит их туда при первом запуске; заметки, история буфера обмена и настройки остаются как были.
- Перезапуск после обновления стал надёжнее.

## 0.2.2 — 2026-10-09

### Новое
- Теперь QuickDesk обновляется сам. Он проверяет новые версии в фоне, рассказывает, что изменилось, и устанавливает их только по вашему решению. Каждое обновление перед установкой проверяется ключом подписи QuickDesk.
- Настройки → Обновления: посмотрите свою версию, проверьте сейчас или отключите автоматическую проверку.
- После обновления QuickDesk один раз показывает, что нового.
- Страница загрузки доступна на вьетнамском и ведёт на исходный код на GitHub.

### Улучшено
- Один значок везде: Dock, меню приложений, окна и трей теперь используют значок QuickDesk.
